01 / ARQUITETURA

Três partes, uma mesma rede

O ESP32 cria a rede COOKIE_EXPRESS e controla a máquina. O computador entra nessa rede e executa um servidor Python. O celular também entra na rede, baixa as páginas do computador e usa a API do ESP para consultar e operar a máquina.

Diagramas de blocos da comunicação atual

Escolha o ambiente abaixo. Os diagramas são vetoriais e estão incorporados neste HTML: funcionam offline, sem buscar bibliotecas ou imagens externas.

O que está sendo usado no teste local.

Ao abrir http://127.0.0.1:8082/, as telas usam o simulador em servidor/testes/demonstracao/. Já a porta 8080 pertence ao servidor normal, cujas telas chamam a API em 192.168.4.1. São processos e bancos separados.

No caminho real, há uma ligação direta navegador ↔ PC para baixar /, /backoffice e /guia. O token autoriza o usuário; a chave privada X-ESP-Key identifica a placa perante o Python. O guia não faz chamadas à máquina.

Qual IP digitar?

No celular, use http://IP_DO_PC:8080/ para a IHM e http://IP_DO_PC:8080/backoffice para o administrador. O endereço do PC é atribuído pelo DHCP do ESP: pode ser 192.168.4.2, 192.168.4.4 ou outro disponível. Consulte ipconfig no computador e procure o IPv4 do adaptador conectado ao COOKIE_EXPRESS.

Dois endereços com funções diferentes.

192.168.4.1 é a API da placa; IP_DO_PC:8080 serve os HTMLs. 127.0.0.1 significa o próprio aparelho: no celular, esse endereço não aponta para o computador. 0.0.0.0 é uma opção de escuta do servidor, não um endereço de navegação.

O firmware procura o Python por broadcast UDP autenticado. Isso evita fixar o IP do PC no ESP, mas não cria um nome de domínio para o navegador. Para abrir a IHM no celular, ainda é necessário informar o IP atual do computador.

02 / FLUXO COMPLETO

O caminho de uma compra

Selecione uma etapa para acompanhar um pedido ilustrativo de duas unidades do slot 1. Esta demonstração é local: não envia pedidos e não aciona o motor.

PC → navegador · GET /

O computador entrega a tela

O Python lê servidor/ihm/index.html e devolve HTML UTF-8. O JavaScript inicializa a interface e consulta status e estoque na API do ESP. A página continua no navegador; os dados operacionais chegam como JSON.

Sequência real do firmware

  1. Login: navegador → ESP → Python. O Python valida a senha e devolve um token de sessão; a IHM mantém o token em memória.
  2. Pedido: a IHM revalida sessão e estoque, então envia POST /api/pedido. O ESP consulta a identidade no Python, valida as quantidades e vincula o pedido ao token.
  3. Agendamento: o controller registra recebido. Após pelo menos 2 segundos, com o emissor IR pulsando no último segundo, a tarefa de controle põe o GPIO do motor do slot selecionado em nível alto e muda para liberando.
  4. Fim do pulso: após pelo menos 3000 ms, a tarefa desliga o GPIO. O pedido continua liberando, esperando confirmação. Não existe entrega automática apenas porque o tempo passou.
  5. Confirmação: A passagem IR confirma a entrega. BOOT/GPIO0 permite confirmação manual com a configuração atual; D pela UART exige MODO_TESTE_SERIAL=1. Uma unidade é entregue, o estoque é reduzido e o slot é salvo na NVS.
  6. Mais unidades: havendo unidades restantes, o estado volta a recebido; aguarda pelo menos 2 segundos, incluindo a antecipação do IR, e inicia outro pulso. Cada cookie precisa de sua confirmação.
  7. Conclusão: ao confirmar a última unidade, o estado vira entregue. O ESP grava um JSON de venda pendente na NVS. A IHM exige estado e contadores coerentes para mostrar sucesso.
  8. Persistência no PC: a tarefa de banco envia a venda. Com HTTP 200, remove a pendência da NVS e da RAM. Se a resposta se perder, o mesmo evento pode ser reenviado sem duplicar o histórico.
Simulação de entrega no estado atual.

D não é um sensor físico. Só é aceito com o motor desligado e um cookie aguardando. R desliga e cancela o pedido corrente; produtos já confirmados não voltam ao estoque, e não há registro de venda parcial nesse cancelamento.

Os arquivos foram separados por responsabilidade. main.c inicia; api.c recebe HTTP; controller.c decide e controla; backend.c conversa com o PC. Os cabeçalhos .h declaram interfaces, e os .c contêm as implementações.

main.c — a ordem de inicialização

Trecho / funçãoExplicação
#includeImporta declarações do SDK e módulos locais. Não executa inicialização sozinho. #define substitui constantes durante a compilação.
iniciar_wifi()Inicializa TCP/IP e eventos, cria interface AP padrão, inicializa driver e configura SSID/senha/canal, WPA2, até quatro clientes e largura HT20 (20 MHz). Inicia o rádio e escreve um log.

Acionamento, IR e modo de teste

acionamento.c configura os seis GPIOs de saída, força todos a LOW antes de ligar o motor escolhido e recusa acionamento com GPIO32 ativo. A chave usa pull-up e fecha para GND. O controller verifica o fim de curso em cada ciclo e nas operações relevantes, persiste maint e impede D/BOOT durante o bloqueio. Não existe retomada automática do pedido interrompido.

sensor_ir.c gera 38 kHz com LEDC no GPIO26: 100 ms ligado e 100 ms de pausa. Interrupcoes nas duas bordas do GPIO27 e amostragem na tarefa reconhecem livre, bloqueado e livre novamente, com filtros de 2 ms. A pausa descarta sequencias incompletas; passagens validas ficam retidas.

main/modo_teste.c trata UART e BOOT/GPIO0, com debounce de 30 ms e um evento por aperto. O modo atual usa IR fisico (MODO_TESTE_SERIAL=0) e permite BOOT apos a parada (BOOT_CONFIRMA_TESTE=1). D exige modo serial ativo. Nao existe timeout de erro IR: apos tres tentativas, aguarda confirmacao.

A tecla R cancela; S mostra diagnóstico. Mesmo estando em servidor/testes/, esse módulo participa do firmware e pode alterar estoque e gerar venda real. O simulador de PC é independente e não exige teclas D/BOOT.

Filtro de passagem IR — código comentado

#pragma once
#include <stdbool.h>
#include <stdint.h>

// Valores iniciais para teste fisico, nao especificacoes do receptor.
#define IR_FILTRO_LIVRE_US 2000
#define IR_FILTRO_BLOQUEIO_US 2000
#define IR_FILTRO_RETORNO_US 2000

#ifdef __cplusplus
#define IR_INLINE constexpr
#else
#define IR_INLINE static inline
#endif

typedef struct {
    bool emitindo, observando, livre, referencia_livre, bloqueado, passagem;
    int64_t valido_apos_us;
    uint32_t passagens;
    bool amostra_valida, nivel_alto;
    int64_t nivel_desde_us, bloqueio_us, ultimo_bloqueio_us;
    uint32_t pulsos_rejeitados;
} ir_eventos_t;

IR_INLINE void ir_eventos_limpar_filtro(ir_eventos_t *e) {
    e->amostra_valida=false;
    e->referencia_livre=false;
    e->bloqueado=false;
    e->bloqueio_us=0;
}

IR_INLINE void ir_eventos_emitir(ir_eventos_t *e, bool ligado, int64_t agora_us) {
    e->emitindo=ligado;
    // A pausa de 100 ms nunca pode completar bloqueio ou retorno pendente.
    ir_eventos_limpar_filtro(e);
    if(ligado) e->valido_apos_us=agora_us+1000;
}

IR_INLINE void ir_eventos_observar(ir_eventos_t *e) {
    e->observando=true;
    ir_eventos_limpar_filtro(e);
    e->passagem=false;
}

IR_INLINE void ir_eventos_validar_nivel(ir_eventos_t *e, int64_t duracao_us) {
    if(e->nivel_alto) {
        if(e->referencia_livre && duracao_us>=IR_FILTRO_BLOQUEIO_US) {
            e->bloqueado=true;
            e->bloqueio_us=duracao_us;
        }
    } else {
        if(e->bloqueado && duracao_us>=IR_FILTRO_RETORNO_US && !e->passagem) {
            e->passagem=true;
            e->passagens++;
            e->ultimo_bloqueio_us=e->bloqueio_us;
        }
        if(duracao_us>=IR_FILTRO_LIVRE_US) e->referencia_livre=true;
    }
}

IR_INLINE void ir_eventos_amostrar(ir_eventos_t *e, int nivel, int64_t agora_us) {
    if(!e->emitindo || agora_us<e->valido_apos_us) return;
    e->livre=nivel==0;
    if(!e->observando) return;
    bool alto=nivel!=0;
    if(!e->amostra_valida) {
        e->amostra_valida=true;
        e->nivel_alto=alto;
        e->nivel_desde_us=agora_us;
        return;
    }
    int64_t duracao_us=agora_us-e->nivel_desde_us;
    // Valida o nivel anterior ANTES de registrar a borda. Assim um ciclo
    // completo entre dois ticks do controlador tambem pode ser capturado.
    ir_eventos_validar_nivel(e,duracao_us);
    if(alto!=e->nivel_alto) {
        if(e->nivel_alto) {
            if(e->referencia_livre && !e->bloqueado && !e->passagem)
                e->pulsos_rejeitados++;
        } else {
            if(e->bloqueado && duracao_us<IR_FILTRO_RETORNO_US && !e->passagem) {
                e->pulsos_rejeitados++;
                e->bloqueado=false;
            }
            e->referencia_livre=duracao_us>=IR_FILTRO_LIVRE_US;
        }
        e->nivel_alto=alto;
        e->nivel_desde_us=agora_us;
    }
}

#undef IR_INLINE

Por que duas tarefas e dois mutexes?

Uma espera de rede pode durar segundos. A tarefa de controle precisa continuar verificando o motor durante esse período. Por isso, tarefa_banco e handlers HTTP chamam o backend sem manter o mutex do controller. O backend possui sua própria trava gate, para que duas chamadas não disputem descoberta e endereço em cache.

Isso evita que um timeout HTTP segure diretamente o estado do motor. Não transforma o pulso em uma garantia elétrica de tempo real: o laço ainda depende do escalonador, de gravações locais e do funcionamento do firmware.

Como interpretar o C usado aqui

Ponteiros e parâmetros de saída

cJSON * aponta para um objeto JSON alocado. cJSON **response permite a função alterar o ponteiro do chamador. int *status devolve o código HTTP por referência. NULL significa ausência de ponteiro válido.

Buffers e strings

Strings C terminam em \0. Um texto de 32 caracteres precisa de 33 posições. sizeof(buffer) fornece a capacidade de um vetor local; strlen mede bytes de texto. Um caractere acentuado pode ocupar mais de um byte UTF-8.

Estruturas e callbacks

.ap={...} e .method=... são inicializadores nomeados de estruturas. A tabela HTTP guarda ponteiros para funções: o caminho selecionado escolhe qual callback será executado.

static, const e recursos

static no nível de arquivo restringe visibilidade; const expressa dado que não deve ser alterado por aquele acesso. malloc/calloc exigem free; árvore cJSON exige cJSON_Delete. goto cleanup reúne a liberação de recursos em falhas.

Uma venda pendente não é um pedido recuperável

A fila pending protege o reenvio de uma venda já concluída. O pedido em andamento fica em RAM e não é reconstruído após desligamento. As baixas de estoque acontecem separadamente; não há uma transação conjunta cobrindo motor, cada confirmação, última venda e envio ao PC.

A persistência atual também não checa todos os retornos NVS: persistencia_salvar_estoque e a sequência não propagam todas as falhas. A flag falha_persistencia detecta problemas específicos ao salvar a pendência, não todos os erros possíveis de flash. A recuperação por apagamento em app_main pode remover dados da NVS inteira.

Senha, sessão e papel de administrador

A senha é derivada com PBKDF2-HMAC-SHA256, salt aleatório e 600000 iterações. O login recalcula a derivação e compara hashes. O cadastro/login retorna um token aleatório de 32 bytes em 64 caracteres hexadecimais; as chamadas seguintes usam Authorization: Bearer ….

O papel role vem da tabela de usuários. Enviar role: admin no cadastro não concede esse papel: o insert usa o padrão cliente. No backoffice, a tela rejeita conta comum e o servidor verifica a permissão novamente nas operações. Logout elimina a sessão do SQLite; expiração também é checada nas consultas autenticadas do Python.

O arquivo de credenciais não é a fonte da autenticação.

admin-inicial.txt auxilia o operador e o verificador de conexão. O servidor valida o hash do banco. Alterar apenas o texto, ou reiniciar o Python, não redefine a senha de um administrador já existente.

Deduplicação da venda

Imagine que o PC grave a venda, mas o ESP não receba a resposta por uma queda no Wi-Fi. O ESP mantém pending e envia de novo com o mesmo evento_id. O Python compara o payload: se for igual, responde 200 com duplicada:true; se o id tiver outros dados, responde 409. Assim, o reenvio de um evento concluído não cria outra venda.

O campo registrado_em na consulta corresponde à gravação no PC em segundos Unix. Não é o instante físico exato da saída do cookie: uma venda pode ficar pendente e chegar depois. O histórico retorna no máximo 30 registros e não calcula faturamento financeiro.

ESP → broadcast 192.168.4.255:8081
CE1:<nonce_aleatorio_32_hex>

Python → endereço de origem do ESP
CE1:<mesmo_nonce>:<porta_http>:<assinatura_64_hex>

O ESP valida a resposta antes de guardar o IP do remetente. Uma mudança de IP é tratada invalidando o endereço em cache após uma falha e descobrindo de novo. É necessário permitir UDP 8081 no firewall e manter a mesma chave no Python e no firmware.

A assinatura de descoberta e a chave HTTP identificam o servidor/placa no protocolo local. As conexões são HTTP comum: os dados não são cifrados em trânsito pelo aplicativo. A chave privada nunca é embutida no JavaScript das telas.

A suíte atual tem 8 cenários Python (servidor e simulador), 22 verificações da IHM e 9 do backoffice. Limites importantes para entender o código

  • Persistência parcial: nem todo retorno NVS é checado e a recuperação da inicialização pode apagar a partição. O sinalizador de erro atual não prova ausência de qualquer falha de flash.
  • Pedido em RAM: desligar a placa perde a sessão e o andamento do pedido. A pendência persistida protege uma venda já concluída; não resolve todo cenário de queda de energia.
  • Polling local: a consulta do pedido compara o token salvo e não revalida logout/expiração no Python em cada leitura. As mutações administrativas e aceitação de pedido fazem validação remota.
  • Disponibilidade aproximada: banco_online significa resposta recente diferente de 503, não sucesso de qualquer operação. Uma sessão pode estar inválida com o transporte funcionando.
  • Tempo do motor por software: o desligamento é verificado no laço; não existe aqui temporizador de segurança externo independente. Os GPIOs dos motores comandam circuitos de potência apropriados.
  • Rede local com HTTP: as credenciais não são cifradas pelo aplicativo. A chave de máquina fica fora do JavaScript e o HMAC autentica a descoberta, mas isso não fornece sigilo de transporte.
  • Histórico apresentado: a tela recebe até 30 vendas; o timestamp é o de gravação no PC. Preço exibido pela IHM não significa cobrança realizada.
  • Dependência da rede do PC: o servidor precisa permanecer ligado e acessível. Os ensaios de energia/modo do Realtek foram diagnósticos e não demonstraram uma solução definitiva para todos os travamentos.

Esses limites estão descritos para que os comentários representem o programa existente. Documentar o firmware não adiciona sensor, recuperação transacional ou integração de pagamento.

/* Inicializa a pilha de rede e cria o ponto de acesso.
 * O ESP é o AP; PC e celular entram nessa mesma rede. A interface AP padrão
 * do ESP-IDF fornece DHCP aos clientes e usa 192.168.4.1 no projeto atual.
 * Esta função não conecta o ESP a um roteador e não fornece acesso à internet.
 */
static void iniciar_wifi(void) {
    ESP_ERROR_CHECK(esp_netif_init());
    ESP_ERROR_CHECK(esp_event_loop_create_default());
    esp_netif_create_default_wifi_ap();
    // WIFI_INIT_CONFIG_DEFAULT preenche parâmetros internos exigidos pelo SDK.
    // O inicializador .ap configura somente a interface de ponto de acesso.
    wifi_init_config_t cfg=WIFI_INIT_CONFIG_DEFAULT();ESP_ERROR_CHECK(esp_wifi_init(&cfg));
    wifi_config_t ap={.ap={
        .ssid=WIFI_SSID, .password=WIFI_PASS, .ssid_len=sizeof(WIFI_SSID)-1,
        .channel=WIFI_CHANNEL, .authmode=WIFI_AUTH_WPA2_PSK, .max_connection=4
    }};
    // Até quatro estações simultâneas; WPA2 exige a senha definida acima.
    // HT20 fixa a largura em 20 MHz para a configuração de compatibilidade local.
    ESP_ERROR_CHECK(esp_wifi_set_mode(WIFI_MODE_AP));
    ESP_ERROR_CHECK(esp_wifi_set_config(WIFI_IF_AP,&ap));
    // Trafego HTTP local e pequeno; HT20 evita depender de coexistencia HT20/40.
    ESP_ERROR_CHECK(esp_wifi_set_bandwidth(WIFI_IF_AP,WIFI_BW_HT20));
    ESP_ERROR_CHECK(esp_wifi_start());
    ESP_LOGI("COOKIE","Wi-Fi %s: http://192.168.4.1, canal %d, 20 MHz", WIFI_SSID,WIFI_CHANNEL);
}

static void aleatorio_hex(char *out, size_t bytes) {
    const char *digits="0123456789abcdef";
    for (size_t i=0;i<bytes;i++) {
        uint8_t b=(uint8_t)esp_random(); out[2*i]=digits[b>>4]; out[2*i+1]=digits[b&15];
    }
    out[2*bytes]=0;
}

// Chamado sob mutex, antes de qualquer ação de motor ou confirmação.
static void verificar_manutencao(void) {
    if(!fim_curso_acionado()) {
        // Porta fechada libera compras, sem retomar o pedido interrompido.
        // Falha NVS mantém o bloqueio; não repetir gravações a cada tick.
        if(dados.manutencao && !dados.falha_persistencia &&
           persistencia_manutencao(&dados,false))
            ESP_LOGI(TAG,"Porta fechada: manutencao liberada automaticamente");
        return;
    }
    // Na entrada em manutenção, garante todas as saídas em LOW. Nos ticks
    // seguintes elas já estão desligadas e nenhum acionamento é permitido.
    // Evita seis escritas GPIO por tick enquanto a porta permanece aberta.
    if(motor_ativo || !dados.manutencao) acionamento_parar();
    motor_ativo=false;
    if(pedido_ativo) {
        pedido_ativo=false; estado=ERRO;
        sensor_ir_encerrar_observacao();
        ir_passagem=false;
        snprintf(mensagem_sensor,sizeof(mensagem_sensor),"Entrega interrompida: maquina em manutencao");
    }
    if(!dados.manutencao) {
        persistencia_manutencao(&dados,true);
        ESP_LOGW(TAG,"Fim de curso acionado: motores parados, manutencao bloqueada");
    }
}

// Iniciar pulso não reduz estoque; fim de curso tem prioridade sobre D/BOOT e IR.
static bool aguardando_confirmacao(void) {
    return !dados.manutencao && !fim_curso_acionado() &&
        pedido_ativo && slot_atual>=0 && !motor_ativo && estado==LIBERANDO;
}

// Cada tentativa mantém o mesmo slot e não altera estoque nem quantidade entregue.
static void iniciar_tentativa_cookie(void) {
    verificar_manutencao();
    if(dados.manutencao) return;
    sensor_ir_preparar_emissao();
    ir_passagem=false;
    emissor_inicio_ms=agora_ms();
    estado=EMITINDO;
    snprintf(mensagem_sensor,sizeof(mensagem_sensor),"Emissor ligado; motor em 1 segundo");
}

static void ligar_motor_tentativa(void) {
    verificar_manutencao();
    if(dados.manutencao) return;
    if(!MODO_TESTE_SERIAL) sensor_ir_iniciar_observacao();
    if(!acionamento_ligar(slot_atual)) {
        sensor_ir_encerrar_observacao();
        verificar_manutencao();
        return;
    }
    ir_passagem=false;
    tentativas_cookie++;
    snprintf(mensagem_sensor,sizeof(mensagem_sensor),"Tentativa %u/%u: aguardando cookie",
             tentativas_cookie,(unsigned)(IR_REPETICOES_MAX+1));
    estado=LIBERANDO;
    motor_parada_ms=0;
    motor_inicio_ms=agora_ms();motor_ativo=true;
    ESP_LOGI(TAG,"Slot %d: tentativa %u/%u; emissor antecipado 1 s",
             slot_atual+1,tentativas_cookie,(unsigned)(IR_REPETICOES_MAX+1));
}

// Operações internas de pedido exigem o mutex adquirido.
static void preparar_proximo_cookie(void) {
    verificar_manutencao();
    if(dados.manutencao) return;
    slot_atual=-1;
    for(int i=0;i<NUM_SABORES;i++) if(restante_pedido[i]>0) {slot_atual=i; break;}
    if(slot_atual<0) return;
    tentativas_cookie=0;
    iniciar_tentativa_cookie();
}

// Baixa uma unidade após confirmação; a última agenda a venda durável.
static void confirmar_entrega(void) {
    verificar_manutencao();
    if(!aguardando_confirmacao()) {
        ESP_LOGW(TAG,"Confirmacao ignorada (sem cookie aguardando)"); return;
    }
    if(dados.estoque[slot_atual]<=0 || restante_pedido[slot_atual]<=0) {
        sensor_ir_encerrar_observacao();
        estado=ERRO;
        snprintf(mensagem_sensor,sizeof(mensagem_sensor),"estoque inconsistente"); return;
    }

    sensor_ir_encerrar_observacao();
    quantidade_entregue[slot_atual]++; restante_pedido[slot_atual]--;
    cookies_entregues++; dados.estoque[slot_atual]--; persistencia_salvar_estoque(&dados,slot_atual);
    snprintf(mensagem_sensor,sizeof(mensagem_sensor),"ok cookie entregue");
    ESP_LOGI(TAG,"Cookie confirmado: slot %d; %d/%d",slot_atual+1,cookies_entregues,total_cookies);
    if(cookies_entregues>=total_cookies) {
        estado=ENTREGUE; pedido_ativo=false;
        persistencia_salvar_venda(&dados,pedido_id,usuario_pedido,quantidade_entregue,total_cookies,evento_pedido); ESP_LOGI(TAG,"Pedido concluido e ultima venda salva");
    } else {

        estado=RECEBIDO;
        slot_atual=-1; instante_pedido_ms=agora_ms();
    }
}

// Cancelar não estorna entregas já confirmadas nem registra venda parcial.
static void resetar_pedido(void) {
    acionamento_parar(); motor_ativo=false;
    sensor_ir_encerrar_observacao();
    ir_passagem=false;
    tentativas_cookie=0; motor_parada_ms=0;
    pedido_ativo=false; estado=OCIOSO;
    mensagem_sensor[0]='\0'; total_cookies=0; cookies_entregues=0; slot_atual=-1;
    memset(restante_pedido,0,sizeof(restante_pedido));
    ESP_LOGW(TAG,"Pedido resetado e GPIO desligado");
}

// Um passo sob mutex. A janela de cada tentativa começa junto com o motor.
static void controle_passo(int64_t t) {
    verificar_manutencao();
    sensor_ir_atualizar();
    if(pedido_ativo && estado==EMITINDO && t-emissor_inicio_ms>=IR_ANTECEDENCIA_MS)
        ligar_motor_tentativa();
    if(motor_ativo && t-motor_inicio_ms>=TEMPO_MOTOR_MS) {
        acionamento_parar(); motor_ativo=false;
        motor_parada_ms=t;
        ESP_LOGI(TAG,"Motor %d DESLIGADO; aguardando %s",slot_atual+1,MODO_TESTE_SERIAL ? "D ou BOOT para simular entrega" : "passagem no sensor IR");
    }

    // Evento retido pela ISR: nao perde um ciclo completo entre dois ticks.
    if(!MODO_TESTE_SERIAL && pedido_ativo && estado==LIBERANDO)
        ir_passagem=ir_passagem || sensor_ir_passagem_detectada();
    unsigned eventos=modo_teste_ler(t,aguardando_confirmacao());
    if(eventos & TESTE_CANCELAR) resetar_pedido();
    else if((!MODO_TESTE_SERIAL && ir_passagem && aguardando_confirmacao()) ||
            (eventos & TESTE_CONFIRMAR))
        confirmar_entrega();
    if(!MODO_TESTE_SERIAL && pedido_ativo && estado==LIBERANDO && !motor_ativo &&
       t-motor_parada_ms>=IR_INTERVALO_REPETICAO_MS && tentativas_cookie<IR_REPETICOES_MAX+1) {
        sensor_ir_encerrar_observacao();
        estado=INTERVALO_REPETICAO;
        instante_pedido_ms=t;
        ESP_LOGI(TAG,"Sem confirmacao; repeticao com intervalo de 2 s, sem erro de IR");
    }
    // O intervalo total inclui o segundo final de antecedencia do emissor.
    if(pedido_ativo && t-instante_pedido_ms>=INTERVALO_COOKIE_MS-IR_ANTECEDENCIA_MS) {
        if(estado==RECEBIDO) preparar_proximo_cookie();
        else if(estado==INTERVALO_REPETICAO) iniciar_tentativa_cookie();
    }
    if(eventos & TESTE_DIAGNOSTICO) {
        sensor_ir_diagnostico();
        modo_teste_diagnostico();
        ESP_LOGI(TAG,"pedido=%d; motor=%d; estado=%s",pedido_ativo,motor_ativo,estados[estado]);
    }
}

// Laço sem HTTP: sensor, temporização do motor e entradas de teste.
static void tarefa_controle(void *arg) {
    while(true) {
        lock();
        controle_passo(agora_ms());
        unlock();
        vTaskDelay(1);
    }
}

static cJSON *erro(const char *msg) { cJSON *j=cJSON_CreateObject(); cJSON_AddBoolToObject(j,"ok",false); cJSON_AddStringToObject(j,"erro",msg); return j; }

static cJSON *ok_obj(void) {cJSON *j=cJSON_CreateObject();cJSON_AddBoolToObject(j,"ok",true);return j;}

static int get_int(cJSON *j,const char *key,int default_value) {
    cJSON *p=cJSON_GetObjectItemCaseSensitive(j,key);
    return cJSON_IsNumber(p) && p->valuedouble==(double)p->valueint ? p->valueint:default_value;
}

// Nunca manter o mutex de estado durante HTTP; disponibilidade expira em 20 s.
int controller_request(esp_http_client_method_t method,const char *path,
                            const char *body,const char *auth,cJSON **out) {
    int code=backend_request(method,path,body,auth,out);
    lock();
    banco_online=(code!=503);
    if(banco_online) banco_ultimo_ok=agora_ms();
    unlock();
    return code;
}

// Comprador/token vêm da sessão validada; aceitar apenas agenda o motor.
cJSON *controller_place_order(cJSON *body, const char *comprador, const char *token, int *status) {
    int qtd[NUM_SABORES]={0},soma=0;char key[12];
    for(int i=0;i<NUM_SABORES;i++) {
        chave_slot(key,sizeof(key),"q",i);
        int v=get_int(body,key,0);
        if(v<0 || v>PEDIDO_MAX) { *status=400; return erro("Quantidade invalida"); }
        qtd[i]=v; soma+=v;
    }

    int total=get_int(body,"total_cookies",-1);
    if(soma<1 || soma>PEDIDO_MAX || soma!=total) {
        *status = 400; return erro("Pedido deve possuir entre 1 e 3 cookies");
    }

    lock();
    verificar_manutencao();
    if(dados.manutencao) {
        unlock();*status=409;
        cJSON *j=erro("Maquina em manutencao. Procure o responsavel.");
        cJSON_AddBoolToObject(j,"manutencao",true);
        return j;
    }
    if(pedido_ativo) { unlock();*status = 409; return erro("Existe um pedido em andamento"); }
    if(dados.venda_pendente[0] || dados.falha_persistencia) {
        unlock();*status = 503; return erro("Aguardando gravacao da venda anterior no banco");
    }
    for(int i=0;i<NUM_SABORES;i++) if(qtd[i]>dados.estoque[i]) {
        cJSON *e=erro("Estoque insuficiente"); cJSON_AddNumberToObject(e,"slot",i+1);
        unlock();*status = 409; return e;
    }

    pedido_id=persistencia_proximo_id();
    snprintf(usuario_pedido,sizeof(usuario_pedido),"%s",comprador);
    snprintf(token_pedido,sizeof(token_pedido),"%s",token);
    aleatorio_hex(evento_pedido,16);
    for(int i=0;i<NUM_SABORES;i++) {
        restante_pedido[i]=qtd[i];quantidade_entregue[i]=0;
    }
    total_cookies=soma;cookies_entregues=0;pedido_ativo=true;
    estado=RECEBIDO; mensagem_sensor[0]='\0';
    slot_atual=-1; instante_pedido_ms=agora_ms();
    cJSON *j=ok_obj(); cJSON_AddNumberToObject(j,"pedido_id",pedido_id);
    cJSON_AddStringToObject(j,"status","recebido");
    ESP_LOGI(TAG,"Pedido #%" PRIu32 " recebido: %d cookies, usuario %s",pedido_id,soma,usuario_pedido);
    unlock();*status = 200; return j;
}

// A API valida papel admin. Ajustes são recusados com pedido ativo.
cJSON *controller_adjust_stock(cJSON *body, bool reposicao, int *status) {
    int slot=get_int(body,"slot",-1),quantidade=get_int(body,"quantidade",-1);

    if(slot<1||slot>NUM_SABORES||quantidade<(reposicao?1:0)) {
        *status = 400; return erro("Dados invalidos");
    }
    lock();
    if(pedido_ativo) {unlock();*status = 409; return erro("Nao alterar estoque com pedido ativo");}
    int i=slot-1;
    int novo=reposicao ? (quantidade>CAPACIDADE_SLOT-dados.estoque[i] ? CAPACIDADE_SLOT : dados.estoque[i]+quantidade) : quantidade;
    if(novo>CAPACIDADE_SLOT) novo=CAPACIDADE_SLOT;
    dados.estoque[i]=novo; persistencia_salvar_estoque(&dados,i);
    cJSON *j=ok_obj();cJSON_AddNumberToObject(j,"slot",slot);
    cJSON_AddNumberToObject(j,"quantidade",dados.estoque[i]);
    unlock();*status = 200; return j;
}

// Copia sob mutex e envia fora dele. Falhas mantêm a fila para reenvio.
static void tarefa_banco(void *arg) {
    while(true) {
        char pending[sizeof(dados.venda_pendente)];
        lock();snprintf(pending,sizeof(pending),"%s",dados.venda_pendente);unlock();
        cJSON *response=NULL;
        if(pending[0]) {
            int code=controller_request(HTTP_METHOD_POST,"/api/vendas",pending,NULL,&response);

            if(code==200) {
                lock();
                persistencia_limpar_pendente(&dados);
                unlock();
            }
            cJSON_Delete(response);response=NULL;
        }

        // Reutiliza o buffer da fila; seis slots cabem sem alocar outra string.
        cJSON *snapshot=controller_inventory();
        bool pronto=cJSON_PrintPreallocated(snapshot,pending,sizeof(pending),false);
        cJSON_Delete(snapshot);
        if(pronto) controller_request(HTTP_METHOD_PUT,"/api/estoque",pending,NULL,&response);
        cJSON_Delete(response);
        vTaskDelay(pdMS_TO_TICKS(SINCRONIZACAO_MS));
    }
}

// Inicialização única, após NVS e antes da API; todos os motores começam desligados.

    configASSERT(mutex);
    acionamento_init();
    modo_teste_init();
    sensor_ir_init();
    persistencia_carregar(&dados);

}

// Saídas dos seis motores e entrada do fim de curso, conforme o esquema da placa.
#include "esp_log.h"
#include "maquina_config.h"
#include "acionamento.h"

static const gpio_num_t motores[]=MOTORES_GPIO;
_Static_assert(sizeof(motores)/sizeof(motores[0])==NUM_SABORES,"Mapa de motores incompleto");

bool fim_curso_acionado(void) {
    // Pull-up mantém HIGH com a chave aberta; contato para GND indica porta aberta.
    return gpio_get_level(FIM_CURSO_GPIO)==FIM_CURSO_ATIVO;
}

void acionamento_parar(void) {
    // Também usado na partida e no cancelamento: desliga mesmo sem slot conhecido.
    for(int i=0;i<NUM_SABORES;i++) gpio_set_level(motores[i],0);
}

bool acionamento_ligar(int slot) {
    // Exclusividade: desliga qualquer saída anterior antes de validar/ligar outra.
    // HIGH é o comando do driver de potência; o GPIO não alimenta o motor.
    acionamento_parar();
    if(slot<0 || slot>=NUM_SABORES || fim_curso_acionado()) return false;
    gpio_set_level(motores[slot],1);
    ESP_LOGI("COOKIE","Motor %d: GPIO%d LIGADO",slot+1,motores[slot]);
    return true;
}

void acionamento_init(void) {
    // A máscara reúne os seis GPIOs em uma única configuração do driver.
    uint64_t mask=0;
    for(int i=0;i<NUM_SABORES;i++) mask|=1ULL<<motores[i];
    gpio_config_t saidas={.pin_bit_mask=mask,.mode=GPIO_MODE_OUTPUT};
    ESP_ERROR_CHECK(gpio_config(&saidas));
    acionamento_parar();
    gpio_config_t chave={.pin_bit_mask=1ULL<<FIM_CURSO_GPIO,.mode=GPIO_MODE_INPUT,
        .pull_up_en=GPIO_PULLUP_ENABLE};
    ESP_ERROR_CHECK(gpio_config(&chave));
}

#include <inttypes.h>
#include "freertos/FreeRTOS.h"
#include "freertos/semphr.h"

#include "sensor_ir_eventos.h"

static portMUX_TYPE ir_mux = portMUX_INITIALIZER_UNLOCKED;
static SemaphoreHandle_t emissao_gate;
static ir_eventos_t ir;
static bool ir_preparado,ir_respondeu;
static int64_t ir_fim_previsto_us;
static int ir_nivel=1;
static int64_t ir_ultima_recepcao_us;
static uint32_t ir_emitidas, ir_recebidas;
static esp_timer_handle_t ir_timer_periodo, ir_timer_fim;

// Chamador segura ir_mux (ISR ou tarefa). LOW significa recepcao de 38 kHz.
static void amostrar(int nivel, int64_t agora) {
    if(!ir.emitindo || agora<ir.valido_apos_us) return;
    if(nivel==0) {
        ir_ultima_recepcao_us=agora;
        if(!ir_respondeu) {ir_respondeu=true;ir_recebidas++;}
    }
    ir_eventos_amostrar(&ir,nivel,agora);
}

static void ir_recepcao(void *arg) {
    portENTER_CRITICAL_ISR(&ir_mux);
    amostrar(gpio_get_level(IR_RX_GPIO),esp_timer_get_time());
    portEXIT_CRITICAL_ISR(&ir_mux);
}

static void duty(unsigned valor) {
    ESP_ERROR_CHECK(ledc_set_duty(LEDC_LOW_SPEED_MODE,LEDC_CHANNEL_0,valor));
    ESP_ERROR_CHECK(ledc_update_duty(LEDC_LOW_SPEED_MODE,LEDC_CHANNEL_0));
}

// emissao_gate serializa LEDC e timers. Nunca tratar o desligamento como cookie.
static void desligar(void) {
    portENTER_CRITICAL(&ir_mux);
    // Fecha um retorno ja estavel antes da pausa, sem esperar o proximo tick.
    amostrar(gpio_get_level(IR_RX_GPIO),esp_timer_get_time());
    ir_eventos_emitir(&ir,false,0);
    portEXIT_CRITICAL(&ir_mux);
    duty(0);
}

static void ligar(void) {
    desligar();
    portENTER_CRITICAL(&ir_mux);
    ir_eventos_emitir(&ir,true,esp_timer_get_time());
    ir_respondeu=false;
    ir_emitidas++;
    portEXIT_CRITICAL(&ir_mux);
    duty(512);
    ir_fim_previsto_us=esp_timer_get_time()+IR_RAJADA_US;
}

static void parar_timer(esp_timer_handle_t timer) {
    esp_err_t e=esp_timer_stop(timer);
    if(e!=ESP_ERR_INVALID_STATE) ESP_ERROR_CHECK(e);
}

static void ir_finalizar_rajada(void *arg) {
    xSemaphoreTake(emissao_gate,portMAX_DELAY);
    if(ir_preparado && esp_timer_get_time()>=ir_fim_previsto_us) desligar();
    xSemaphoreGive(emissao_gate);
}

static void ir_iniciar_rajada(void *arg) {
    xSemaphoreTake(emissao_gate,portMAX_DELAY);
    if(ir_preparado) {
        parar_timer(ir_timer_fim);
        ligar();
        ESP_ERROR_CHECK(esp_timer_start_once(ir_timer_fim,IR_RAJADA_US));
    }
    xSemaphoreGive(emissao_gate);
}

// Chamador segura emissao_gate. Reinicia a fase do ciclo sem capturar cookie.
static void preparar_emissao(void) {
    parar_timer(ir_timer_periodo);
    parar_timer(ir_timer_fim);
    desligar();
    portENTER_CRITICAL(&ir_mux);
    ir_preparado=true;
    ir.observando=false;
    ir.passagem=false;
    portEXIT_CRITICAL(&ir_mux);
    ligar();
    ESP_ERROR_CHECK(esp_timer_start_once(ir_timer_fim,IR_RAJADA_US));
    ESP_ERROR_CHECK(esp_timer_start_periodic(ir_timer_periodo,IR_PERIODO_US));
}

void sensor_ir_preparar_emissao(void) {
    xSemaphoreTake(emissao_gate,portMAX_DELAY);
    preparar_emissao();
    xSemaphoreGive(emissao_gate);
}

void sensor_ir_iniciar_observacao(void) {
    xSemaphoreTake(emissao_gate,portMAX_DELAY);
    if(!ir_preparado) preparar_emissao();
    portENTER_CRITICAL(&ir_mux);
    ir_eventos_observar(&ir); // O segundo de antecedencia nao confirma entrega.
    portEXIT_CRITICAL(&ir_mux);
    xSemaphoreGive(emissao_gate);
}

void sensor_ir_encerrar_observacao(void) {
    xSemaphoreTake(emissao_gate,portMAX_DELAY);
    parar_timer(ir_timer_periodo);
    parar_timer(ir_timer_fim);
    desligar();
    portENTER_CRITICAL(&ir_mux);
    ir.observando=false;
    ir_preparado=false;
    portEXIT_CRITICAL(&ir_mux);
    xSemaphoreGive(emissao_gate);
}

    portEXIT_CRITICAL(&ir_mux);

            .mode=GPIO_MODE_INPUT,.pull_up_en=GPIO_PULLUP_ENABLE};

    }

unsigned modo_teste_ler(int64_t t, bool pode_confirmar) {
    unsigned eventos=0;
    if(MODO_TESTE_SERIAL || BOOT_CONFIRMA_TESTE) {
        int nivel=gpio_get_level(BOTAO_TESTE_GPIO);
        if(nivel!=candidato) {
            candidato=nivel; desde=t;
            elegivel=nivel==0 && pode_confirmar;
        }
        if(nivel!=estavel && t-desde>=BOTAO_DEBOUNCE_MS) {
            estavel=nivel;
            if(nivel==1) {
                armado=true;
                ESP_LOGI("COOKIE","BOOT GPIO0 SOLTO");
            } else {
                ESP_LOGI("COOKIE","BOOT GPIO0 PRESSIONADO");
                if(armado && elegivel) eventos|=TESTE_CONFIRMAR;
                else ESP_LOGW("COOKIE","BOOT ignorado: aguarde pedido em liberacao e motor parado");
                // Só uma soltura estável arma novamente; segurar não repete.
                armado=false;
            }
        }
    }
    uint8_t comando;
    if(uart_read_bytes(UART_NUM_0,&comando,1,0)>0) {
        switch(comando) {
            case 'd': case 'D':
                if(MODO_TESTE_SERIAL) eventos|=TESTE_CONFIRMAR;
                else ESP_LOGW("COOKIE","D desativado: entrega exige sensor IR");
                break;
            case 'r': case 'R': eventos|=TESTE_CANCELAR; break;
            case 's': case 'S': eventos|=TESTE_DIAGNOSTICO; break;
        }
    }
    return eventos;
}

void modo_teste_diagnostico(void) {
    ESP_LOGI("COOKIE","TESTE=%d; BOOT_TESTE=%d; BOOT GPIO0=%d; armado=%d",
        MODO_TESTE_SERIAL,BOOT_CONFIRMA_TESTE,gpio_get_level(BOTAO_TESTE_GPIO),armado);
}

static void chave_slot(char *dst, size_t n, const char *prefixo, int i) {
    snprintf(dst,n,"%s%d",prefixo,i+1);
}
void persistencia_salvar_estoque(persistencia_t *dados, int i) {
    // Contrato legado: falhas de estoque/seq não são propagadas à resposta HTTP.
    nvs_handle_t h;
    if (nvs_open("cookievm", NVS_READWRITE, &h) != ESP_OK) return;
    char k[16]; chave_slot(k,sizeof(k),"s",i);
    nvs_set_i32(h,k,dados->estoque[i]); nvs_commit(h); nvs_close(h);
}

// As chaves NVS são preservadas; não recupera pedido interrompido.
void persistencia_carregar(persistencia_t *dados) {
    nvs_handle_t h;
    if (nvs_open("cookievm", NVS_READWRITE, &h) != ESP_OK) {
        dados->falha_persistencia=true; ESP_LOGE(TAG,"Falha NVS"); return;
    }

    for(int i=0;i<NUM_SABORES;i++) {
        char k[16]; int32_t v=ESTOQUE_INICIAL; chave_slot(k,sizeof(k),"s",i);
        nvs_get_i32(h,k,&v); dados->estoque[i]=(v>=0 && v<=CAPACIDADE_SLOT)?v:ESTOQUE_INICIAL;
        chave_slot(k,sizeof(k),"saleq",i); v=0; nvs_get_i32(h,k,&v); dados->ultima_venda_qtd[i]=v;
    }

    nvs_get_u32(h,"saleid",&dados->ultima_venda_id);
    nvs_get_i32(h,"saletotal",(int32_t*)&dados->ultima_venda_total);
    size_t len=sizeof(dados->ultima_venda_usuario);
    if(nvs_get_str(h,"saleuser",dados->ultima_venda_usuario,&len)!=ESP_OK) dados->ultima_venda_usuario[0]='\0';
    len=sizeof(dados->venda_pendente);
    if(nvs_get_str(h,"pending",dados->venda_pendente,&len)!=ESP_OK) dados->venda_pendente[0]=0;
    uint8_t manutencao=0;
    esp_err_t e=nvs_get_u8(h,"maint",&manutencao);
    dados->manutencao=manutencao!=0;
    if(e!=ESP_OK && e!=ESP_ERR_NVS_NOT_FOUND) dados->falha_persistencia=true;
    nvs_close(h);
}

bool persistencia_manutencao(persistencia_t *dados, bool ativa) {
    if(ativa) dados->manutencao=true; // Bloqueia em RAM mesmo se a flash falhar.
    nvs_handle_t h;
    esp_err_t e=nvs_open("cookievm",NVS_READWRITE,&h);
    if(e==ESP_OK) {
        e=nvs_set_u8(h,"maint",ativa);
        if(e==ESP_OK) e=nvs_commit(h);
        nvs_close(h);
    }
    if(e!=ESP_OK) dados->falha_persistencia=true;
    else dados->manutencao=ativa;
    return e==ESP_OK;
}

    }

    if(saved!=ESP_OK) dados->falha_persistencia=true;
}

/* api.c — servidor HTTP da placa: JSON, autenticação e despacho de rotas.
 * O navegador baixa HTML no PC e chama http://192.168.4.1 para operar a máquina.
 * Contas e histórico são encaminhados ao Python; motor/estoque ficam no controller.
 * Nenhuma rota deste arquivo serve o conteúdo HTML da IHM ou do backoffice.
 */
// SDK HTTP: requisições/respostas; Wi-Fi: canal e quantidade de clientes no AP.
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "esp_http_server.h"

// Limite do corpo recebido pela placa em bytes, antes da alocação do buffer.
#define BODY_MAX 2048

// Cria uma árvore JSON de erro. reply assume sua propriedade e a destrói.
static cJSON *error(const char *message) {
    cJSON *json = cJSON_CreateObject();
    cJSON_AddBoolToObject(json, "ok", false);
    cJSON_AddStringToObject(json, "erro", message);
    return json;
}

/* Libera as chamadas feitas pelo HTML do PC a uma origem diferente (ESP).
 * OPTIONS é o preflight do navegador. CORS não autentica usuários; Bearer e
 * permissões são verificados pelas rotas. Não substitui HTTPS nem protege a rede.
 */
static void cors(httpd_req_t *req) {
    httpd_resp_set_hdr(req, "Access-Control-Allow-Origin", "*");
    httpd_resp_set_hdr(req, "Access-Control-Allow-Methods", "GET, POST, OPTIONS");
    httpd_resp_set_hdr(req, "Access-Control-Allow-Headers", "Content-Type, Authorization");
    httpd_resp_set_hdr(req, "Access-Control-Allow-Private-Network", "true");
}

/* Envia JSON e consome o objeto recebido, inclusive na falha de serialização.
 * cJSON_PrintUnformatted cria uma string separada; ela é liberada após o envio.
 * no-store evita guardar respostas de sessão/estoque em cache HTTP.
 * O código numérico é o status real; a frase auxiliar é OK ou Error.
 */
static esp_err_t reply(httpd_req_t *req, int code, cJSON *json) {
    char *body = cJSON_PrintUnformatted(json);
    cJSON_Delete(json);
    cors(req);
    if (!body) return httpd_resp_send_err(req, HTTPD_500_INTERNAL_SERVER_ERROR, "Sem memoria");
    char status[32];
    snprintf(status, sizeof(status), "%d %s", code, code == 200 ? "OK" : "Error");
    httpd_resp_set_status(req, status);
    httpd_resp_set_type(req, "application/json");
    httpd_resp_set_hdr(req, "Cache-Control", "no-store");
    esp_err_t result = httpd_resp_sendstr(req, body);
    free(body);
    return result;
}

/* Lê o corpo completo (1..2048 bytes) e exige um objeto JSON.
 * Uma recepção pode vir fragmentada: o laço acumula até content_len.
 * calloc reserva um byte extra já zerado para terminar a string C.
 * Em erro, a função já responde HTTP e retorna NULL; não responder duas vezes.
 * Em sucesso, o chamador destrói a árvore com cJSON_Delete.
 */
static cJSON *read_body(httpd_req_t *req) {
    if (req->content_len <= 0 || req->content_len > BODY_MAX) {
        reply(req, 400, error("Corpo JSON ausente ou maior que 2048 bytes"));
        return NULL;
    }
    char *raw = calloc(req->content_len + 1, 1);
    if (!raw) {
        reply(req, 503, error("Sem memoria"));
        return NULL;
    }
    int received = 0;
    while (received < req->content_len) {
        int size = httpd_req_recv(req, raw + received, req->content_len - received);
        if (size <= 0) {
            free(raw);
            reply(req, 400, error("Corpo JSON incompleto"));
            return NULL;
        }
        received += size;
    }
    cJSON *json = cJSON_Parse(raw);
    free(raw);
    if (!cJSON_IsObject(json)) {
        cJSON_Delete(json);
        reply(req, 400, error("Objeto JSON invalido"));
        return NULL;
    }
    return json;
}

// Copia o cabeçalho completo "Bearer <token>" para um buffer de 96 bytes.
// Inicializa vazio: cabeçalho ausente/inadequado não deve reutilizar memória antiga.
static void authorization(httpd_req_t *req, char token[96]) {
    token[0] = 0;
    httpd_req_get_hdr_value_str(req, "Authorization", token, 96);
}

// Retorna ponteiro emprestado de um campo string; não liberar separadamente.
// O ponteiro só continua válido enquanto o JSON pai existir.
static const char *string(cJSON *json, const char *key) {
    cJSON *value = cJSON_GetObjectItemCaseSensitive(json, key);
    return cJSON_IsString(value) ? value->valuestring : NULL;
}

/* Verifica o Bearer no Python por /api/auth/me e, se exigido, role=admin.
 * name é opcional; quando presente, o chamador reserva pelo menos 64 bytes.
 * O limite em BYTES evita ultrapassar esse destino com nomes UTF-8 acentuados.
 * Não confia no nome nem no papel enviados pelo navegador no corpo do pedido.
 * Destrói a resposta do Python depois de copiar os dados necessários.
 */
static int authorize(httpd_req_t *req, bool admin, char *name) {
    char token[96];
    authorization(req, token);
    if (strncmp(token, "Bearer ", 7) != 0 || !token[7]) return 401;
    cJSON *json = NULL;
    int code = controller_request(HTTP_METHOD_GET, "/api/auth/me", NULL, token, &json);
    if (code == 200) {
        cJSON *user = cJSON_GetObjectItemCaseSensitive(json, "usuario");
        const char *user_name = string(user, "nome"), *role = string(user, "role");
        if (!user_name || strlen(user_name) > 63) code = 503;
        else if (admin && (!role || strcmp(role, "admin") != 0)) code = 403;
        else if (name) strcpy(name, user_name);
    }
    cJSON_Delete(json);
    return code;
}

/* Ponte para login/cadastro/sessão e consulta de vendas.
 * Preserva método, caminho, Authorization, status e JSON da resposta do Python.
 * A chave privada de máquina é acrescentada somente pelo backend do ESP.
 * Para /api/vendas GET, o próprio Python exige admin. Login/cadastro não exigem
 * sessão anterior; suas validações também pertencem ao Python.
 */
static esp_err_t proxy(httpd_req_t *req) {
    char token[96];
    authorization(req, token);
    char *raw = NULL;
    if (req->method == HTTP_POST) {
        cJSON *body = read_body(req);
        if (!body) return ESP_OK; // read_body ja respondeu ao erro.
        raw = cJSON_PrintUnformatted(body);
        cJSON_Delete(body);
        if (!raw) return reply(req, 503, error("Sem memoria"));
    }
    cJSON *json = NULL;
    int code = controller_request(req->method == HTTP_POST ? HTTP_METHOD_POST : HTTP_METHOD_GET,
                                  req->uri, raw, token, &json);
    free(raw);
    if (!json) json = error("Banco indisponivel. Conecte o PC ao Wi-Fi do ESP e inicie o Python.");
    return reply(req, code, json);
}

// Acrescenta canal Wi-Fi e número de estações ao snapshot operacional do controller.
static esp_err_t status(httpd_req_t *req) {
    cJSON *json = controller_status();
    uint8_t channel = 0;
    wifi_second_chan_t secondary;
    if (esp_wifi_get_channel(&channel, &secondary) == ESP_OK)
        cJSON_AddNumberToObject(json, "wifi_canal", channel);
    wifi_sta_list_t clients = {0};
    esp_wifi_ap_get_sta_list(&clients);
    cJSON_AddNumberToObject(json, "clientes_conectados", clients.num);
    return reply(req, 200, json);
}

// Polling do pedido: o controller compara a sessão com a que aceitou o pedido.
static esp_err_t order_status(httpd_req_t *req) {
    char token[96];
    authorization(req, token);
    int code;
    cJSON *json = controller_order_status(token, &code);
    return reply(req, code, json);

// A última venda inclui usuário; esta rota exige sessão de administrador.
static esp_err_t last_sale(httpd_req_t *req) {
    int code = authorize(req, true, NULL);
    if (code != 200) return reply(req, code, error("Acesso administrativo necessario"));
    return reply(req, 200, controller_last_sale());
}

// Retirada do bloqueio exige administrador e chave fisicamente liberada.
static esp_err_t maintenance_clear(httpd_req_t *req) {
    int code=authorize(req,true,NULL);
    if(code!=200) return reply(req,code,error("Acesso administrativo necessario"));
    cJSON *body=read_body(req);
    if(!body) return ESP_OK;
    cJSON_Delete(body);
    cJSON *json=controller_clear_maintenance(&code);
    return reply(req,code,json);
}

/* Entrada comum das mutações locais: pedido de cliente ou estoque de admin.
 * Autoriza ANTES de aceitar o corpo e passar ao controller.
 * O controller apenas empresta body, portanto este handler deve destruí-lo.
 * Ajustar estoque não aciona motor; fazer pedido agenda a tarefa de controle.
 */
static esp_err_t change(httpd_req_t *req) {
    bool order = strcmp(req->uri, "/api/pedido") == 0;
    char buyer[64], token[96];
    int code = authorize(req, !order, buyer);
    if (code != 200) return reply(req, code, error("Sessao invalida, acesso negado ou banco indisponivel"));
    cJSON *body = read_body(req);
    if (!body) return ESP_OK;
    authorization(req, token);
    cJSON *json = order ? controller_place_order(body, buyer, token, &code) :
        controller_adjust_stock(body, strcmp(req->uri, "/api/estoque/reposicao") == 0, &code);
    cJSON_Delete(body);
    return reply(req, code, json);
}

/* Roteador: um handler curinga para cada método, com tabela de caminhos exatos.
 * OPTIONS responde 204 para o navegador; os demais consultam método + URI.
 * Os caminhos atuais não aceitam sufixos ou query strings arbitrárias, pois
 * a comparação usa strcmp no req->uri. Recurso desconhecido devolve JSON 404.
 */
static esp_err_t route(httpd_req_t *req) {
    // Um unico preflight atende os HTMLs hospedados no PC.
    if (req->method == HTTP_OPTIONS) {
        cors(req);
        httpd_resp_set_status(req, "204 No Content");
        return httpd_resp_send(req, NULL, 0);
    }
    // Cada entrada associa caminho e método a uma função do tipo handler HTTP.
    static const struct {
        const char *path;
        httpd_method_t method;
        esp_err_t (*handler)(httpd_req_t *);
    } routes[] = {
        {"/", HTTP_GET, status},
        {"/api/status", HTTP_GET, status},
        {"/api/estoque", HTTP_GET, inventory},
        {"/api/pedido/status", HTTP_GET, order_status},
        {"/api/venda/ultima", HTTP_GET, last_sale},
        {"/api/vendas", HTTP_GET, proxy}, // O Python exige sessao admin nesta rota.
        {"/api/auth/register", HTTP_POST, proxy},
        {"/api/auth/login", HTTP_POST, proxy},
        {"/api/auth/me", HTTP_GET, proxy},
        {"/api/auth/logout", HTTP_POST, proxy},
        {"/api/pedido", HTTP_POST, change},
        {"/api/estoque/reposicao", HTTP_POST, change},
        {"/api/estoque/ajuste", HTTP_POST, change},
        {"/api/manutencao/liberar", HTTP_POST, maintenance_clear},
    };
    for (size_t i = 0; i < sizeof(routes) / sizeof(routes[0]); i++)
        if (req->method == routes[i].method && strcmp(req->uri, routes[i].path) == 0)
            return routes[i].handler(req);
    return reply(req, 404, error("Rota nao encontrada. Abra a IHM e o backoffice no servidor do PC."));
}

/* Sobe o servidor do ESP na porta HTTP padrão 80.
 * Há três registros curinga (GET/POST/OPTIONS), não um registro SDK por endpoint.
 * A tabela em route faz o despacho final. A pilha HTTP tem 8192 bytes; envio tem
 * timeout de 10 s. ESP_ERROR_CHECK interrompe a partida se o servidor falhar.
 */
void api_start(void) {
    httpd_handle_t server = NULL;
    httpd_config_t config = HTTPD_DEFAULT_CONFIG();
    config.uri_match_fn = httpd_uri_match_wildcard;
    config.max_uri_handlers = 3;
    config.stack_size = 8192;
    config.send_wait_timeout = 10;
    ESP_ERROR_CHECK(httpd_start(&server, &config));
    httpd_uri_t uri = {.uri = "/*", .handler = route};
    const httpd_method_t methods[] = {HTTP_GET, HTTP_POST, HTTP_OPTIONS};
    for (size_t i = 0; i < sizeof(methods) / sizeof(methods[0]); i++) {
        uri.method = methods[i];
        ESP_ERROR_CHECK(httpd_register_uri_handler(server, &uri));
    }
}

/* backend.c — transporte ESP -> Python.
 * Descobre o IPv4 do PC por UDP com desafio HMAC e usa HTTP para a API do banco.
 * Uma trava exclusiva serializa as requisições e protege o endereço em cache.
 * Esta trava é diferente do mutex do controller: espera de rede não segura
 * diretamente o estado físico do motor.
 * backend_secret.h é gerado localmente; não copiar seu conteúdo para documentação.
 */
// lwIP fornece sockets; mbedTLS calcula HMAC-SHA256; FreeRTOS fornece o mutex.
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "freertos/FreeRTOS.h"
#include "freertos/semphr.h"
#include "lwip/sockets.h"
#include "esp_random.h"
#include "mbedtls/md.h"
#include "backend.h"
#include "backend_secret.h"

// gate: uma requisição por vez; base: URL descoberta (por exemplo http://IP:8080).
// O buffer estático inicia zerado; base vazia solicita nova descoberta.
static SemaphoreHandle_t gate;
static char base[80];

// Prepara o mutex antes de API e tarefa_banco começarem a usar este módulo.
void backend_init(void) {
    gate = xSemaphoreCreateMutex();
    configASSERT(gate);
}

/* Busca o Python na sub-rede do AP sem fixar o IP do PC.
 * Envia CE1:<nonce> para 192.168.4.255:8081. O Python responde
 * CE1:<mesmo_nonce>:<porta_http>:<hmac_sha256(nonce:porta)>.
 * A assinatura usa BACKEND_KEY compartilhada. O desafio aleatório dificulta
 * reaproveitar uma resposta antiga; isto autentica a descoberta, não cifra HTTP.
 * Chamador já segura gate. Fecha o socket ao terminar e só grava base se validar.
 */
static bool discover(void) {
    int fd = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    if (fd < 0) return false;
    // Broadcast precisa ser habilitado. A recepção tem timeout de 1 segundo.
    // htons converte a porta para ordem de bytes de rede; inet_addr converte IPv4.
    int enabled = 1;
    setsockopt(fd, SOL_SOCKET, SO_BROADCAST, &enabled, sizeof(enabled));
    struct timeval timeout = {.tv_sec=1, .tv_usec=0};
    setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &timeout, sizeof(timeout));
    struct sockaddr_in destination = {.sin_family=AF_INET, .sin_port=htons(8081)};
    destination.sin_addr.s_addr = inet_addr("192.168.4.255");
    // Quatro números de 32 bits formam 32 caracteres hexadecimais + NUL.
    char nonce[33], probe[40], reply[160];
    for (int i=0;i<4;i++) snprintf(nonce+8*i, 9, "%08lx", (unsigned long)esp_random());
    snprintf(probe, sizeof(probe), "CE1:%s", nonce);
    sendto(fd, probe, strlen(probe), 0, (struct sockaddr *)&destination, sizeof(destination));
    struct sockaddr_in source;
    socklen_t source_size = sizeof(source);
    bool found = false;
    // Ignora respostas invalidas; ha ate quatro clientes no AP.
    for (int attempt=0;attempt<4;attempt++) {
        int n = recvfrom(fd, reply, sizeof(reply)-1, 0, (struct sockaddr *)&source, &source_size);
        if (n<=0) break;
        reply[n]=0;
        char echoed[33], signature[65], extra;
        unsigned port;
        // Campos limitados pelos tamanhos dos buffers; %c detecta dados extras.
        // Só aceita nonce correto, assinatura de 64 hex e porta válida 1..65535.
        if (sscanf(reply,"CE1:%32[0-9a-f]:%u:%64[0-9a-f]%c",echoed,&port,signature,&extra)!=3 ||
            strcmp(echoed,nonce)!=0 || strlen(signature)!=64 || port<1 || port>65535) continue;
        char message[48], expected[65]; unsigned char digest[32];
        snprintf(message,sizeof(message),"%s:%u",nonce,port);
        // Recalcula a assinatura local: nunca enviar a chave no pacote de descoberta.
        mbedtls_md_hmac(mbedtls_md_info_from_type(MBEDTLS_MD_SHA256),
                        (const unsigned char *)BACKEND_KEY,strlen(BACKEND_KEY),
                        (const unsigned char *)message,strlen(message),digest);
        for (int i=0;i<32;i++) snprintf(expected+2*i,3,"%02x",digest[i]);
        // Compara todos os 64 caracteres, acumulando diferenças em vez de sair
        // no primeiro caractere desigual. Qualquer diferença invalida a resposta.
        unsigned difference=0;
        for (int i=0;i<64;i++) difference |= (unsigned char)signature[i] ^ (unsigned char)expected[i];
        if (difference) continue;
        // O IP vem do remetente UDP; a porta HTTP vem do anúncio autenticado.
        // Não assumir que o PC sempre recebe 192.168.4.2 do DHCP.
        char ip[INET_ADDRSTRLEN];
        inet_ntop(AF_INET,&source.sin_addr,ip,sizeof(ip));
        snprintf(base,sizeof(base),"http://%s:%u",ip,port);
        found=true; break;
    }
    close(fd);
    return found;
}

/* Executa uma chamada JSON autenticada na API do Python.
 * method/path/body são emprestados. authorization é opcional e pertence ao usuário;
 * X-ESP-Key identifica a placa. O navegador nunca precisa conhecer BACKEND_KEY.
 * Inicializa *response=NULL. Em resposta JSON válida, o chamador recebe a árvore
 * e deve destruí-la. Retorna o status recebido, ou 503 se transporte/JSON falhar.
 * Aguarda gate por até 10 s; o cliente tem timeout de E/S de 5 s. Esses valores
 * são etapas, não um limite global único para toda a operação.
 */
int backend_request(esp_http_client_method_t method, const char *path,
                    const char *body, const char *authorization, cJSON **response) {
    *response=NULL;
    if (xSemaphoreTake(gate,pdMS_TO_TICKS(10000))!=pdTRUE) return 503;
    int code=503;
    if (!base[0] && !discover()) goto done;
    char url[160]; snprintf(url,sizeof(url),"%s%s",base,path);
    // Redirecionamento automático é desativado para não reenviar os cabeçalhos
    // de autenticação a outro destino. Endereço e resposta têm limites explícitos.
    esp_http_client_config_t cfg={.url=url,.timeout_ms=5000,.disable_auto_redirect=true,.buffer_size=1024};
    esp_http_client_handle_t client=esp_http_client_init(&cfg);
    if (!client) goto done;
    esp_http_client_set_method(client,method);
    esp_http_client_set_header(client,"X-ESP-Key",BACKEND_KEY);
    esp_http_client_set_header(client,"Content-Type","application/json");
    if (authorization && authorization[0]) esp_http_client_set_header(client,"Authorization",authorization);
    int length=body ? (int)strlen(body):0;
    if (esp_http_client_open(client,length)!=ESP_OK) goto cleanup;
    // Escrita HTTP pode ser parcial; só prossegue após enviar todo o corpo.
    for (int sent=0;sent<length;) {
        int n=esp_http_client_write(client,body+sent,length-sent);
        if(n<=0) goto cleanup;
        sent+=n;
    }
    if(esp_http_client_fetch_headers(client)<0) goto cleanup;
    // Até 24575 bytes de resposta útil: atingir 24576 é tratado como grande demais.
    // O byte adicional permite NUL sem ultrapassar o buffer. Ler não garante
    // mensagem completa; o teste do SDK abaixo também precisa confirmar o término.
    char *raw=malloc(24577);
    if(!raw) goto cleanup;
    int used=0;
    while(used<24576) {
        int n=esp_http_client_read(client,raw+used,24576-used);
        if(n<0) {free(raw);goto cleanup;}
        if(n==0) break;
        used+=n;
    }
    raw[used]=0;
    if(used<24576 && esp_http_client_is_complete_data_received(client)) *response=cJSON_Parse(raw);
    free(raw);
    if(*response) code=esp_http_client_get_status_code(client);
// Saída comum após abrir o handle: cleanup fecha/libera o cliente HTTP.
// Falha 503 invalida o IP em cache; a próxima chamada tenta descobrir de novo.
cleanup:
    esp_http_client_cleanup(client);
    if(code==503) base[0]=0; // Redescobre IP depois de falha ou troca de rede.
// Todo caminho que adquiriu gate passa por esta liberação, inclusive erros.
done:
    xSemaphoreGive(gate);
    return code;
}

Glossário, referências e manutenção

TermoSignificado no projeto
AP / DHCPAccess Point é o Wi-Fi criado pelo ESP. DHCP atribui endereço aos clientes, incluindo PC e celular.
IHMInterface Homem-Máquina: tela do cliente para interagir com a máquina.
BackofficeTela administrativa para consultar vendas e gerenciar estoque.
HTTP / JSONHTTP transporta as requisições; JSON representa objetos, campos e listas nos corpos das mensagens.
Endpoint / handler / proxyEndpoint é método+caminho da API; handler é a função que atende; proxy encaminha a outro servidor.
CORS / preflightRegras de navegador para chamada entre origens. Preflight OPTIONS consulta permissões antes da chamada principal.
Bearer / roleBearer transporta o token de sessão. Role é o papel da conta, como cliente ou admin.
Hash / salt / HMAC / nonceHash gera resumo; salt distingue derivações de senha; HMAC autentica mensagem com uma chave; nonce é desafio novo para aquela troca.
GPIO / UARTGPIO18/19/21/22/23/25 comandam os seis motores; GPIO32 lê o fim de curso. UART0 fornece logs e comandos D/R/S.
Task / mutexTask é uma tarefa escalonada pelo FreeRTOS; mutex evita alterações simultâneas incompatíveis em dados compartilhados.
NVS / namespace / commitFlash de chave/valor do ESP, agrupamento de chaves e confirmação da escrita persistente.
WAL / transaçãoModo de journal usado pelo SQLite e unidade de alterações que faz commit ou rollback. Não conecta automaticamente uma transação SQLite às ações físicas do ESP.
IdempotênciaRepetir a mesma venda com mesmo evento não cria outra linha, desde que o conteúdo seja idêntico.
Build / flash / monitorCompilar o binário / gravar na placa / ler e interagir com a serial. São operações diferentes.
